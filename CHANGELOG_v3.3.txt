N1Z444R MACRO CW v3.3 CHANGELOG
===============================

- Fixed the final ESC being ignored by Roblox.
- Found and fixed an older saved setting that could store Enter as the fourth key.
- Added automatic settings migration to restore the intended final ESC.
- The final ESC is now a separate, reliable input after every chord key is released.
- Added a configurable delay before the fourth key (180 ms by default).
- Added a dedicated fourth-key duration (120 ms by default).
- Added clear "ESC LOCK" status indicators.
- Reorganized the sequence editor into Input Route and Reliability Timing cards.
- Added stronger card borders, section markers, refined gradients, and cleaner spacing.
- Kept F3 emergency stop, popup recovery, mini HUD, languages, and server rotation.
