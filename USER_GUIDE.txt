N1Z444R MACRO CW v3.5
=====================

DEFAULT SEQUENCE

SPACE -> 4 -> hold left click for 2.0-2.5 seconds
-> ESC -> R -> ENTER -> ESC -> wait 6-7 seconds -> repeat

Each reset key is pressed and released separately. The final ESC waits for
the Roblox confirmation transition and uses a dedicated longer press.

QUICK START

1. Close every older macro version, including tray icons.
2. Open Roblox and join Combat Warriors.
3. Run N1Z444R_Macro_CW_v3.5_PROTECTED.exe.
4. Open the sequence editor and review the values.
5. Keep Roblox visible and focused.
6. Start playback.
7. Press F3 at any time for an immediate emergency stop.

RECOMMENDED FINAL ESC SETTINGS

- Delay before final key: 650 ms.
- Final key duration: 180 ms.
- Final key: Escape.

TROUBLESHOOTING

- If your PC renders the reset dialog slowly, increase the final-key delay.
- Do not reduce the final-key duration below the recommended value.
- Keep popup recovery enabled for round-end screens.
- Server rotation requires Roblox to be open and an Internet connection.

The package contains no source code.
